# Provenance and public-release boundary

This repository is a clean-history portfolio derivative of an independently owned, self-hosted n8n job-monitor design.

The public artifacts were written specifically for recruiter and technical review. They reproduce the architecture and deterministic decision pattern with fictional fixtures, but they are not copies of the deployed workflow export.

Excluded material includes:

- private Git history and deployment files;
- hostnames, addresses, ports, routes, and service topology;
- credential identifiers, tokens, notification destinations, and account metadata;
- database base, table, project, and record identifiers;
- personal job-search criteria, application history, and review notes;
- production execution data, logs, and failure traces;
- source-specific operational configuration.

The repository makes no claim that its credential-free demo writes to a real database or sends a real Slack message. Those capabilities belong to the inspected private deployment and are described only at the architectural level.
