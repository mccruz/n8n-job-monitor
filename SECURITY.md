# Security policy

## Public scope

This repository contains fictional fixtures and credential-free n8n workflows. It should not contain production workflow exports, secrets, private endpoints, notification destinations, database identifiers, personal job-search data, or execution logs.

## Reporting a concern

If you find a value that appears to expose private or sensitive information, do not reuse it. Open a GitHub security advisory or contact the repository owner through the public GitHub profile.

## Safe use

- Import the demo only into an n8n instance you control.
- Review any workflow before activating it.
- Keep credentials in n8n's credential store, never inside workflow JSON.
- Use documented public sources and respect their terms and rate limits.
- Keep the demo in preview mode unless you intentionally add and review external integrations.
